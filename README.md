# 競馬予想アプリ集

ブラウザだけで動く、無料・オフラインの競馬予想ツールです。インストール不要・サーバー不要・データは端末内のみに保存されます。

## 収録アプリ

### 🐎 ウマメーター AI（`keiba-ai.html`）— NEW
**期待値(EV)ベースの確率エンジン**を核にした新アプリ。「当てる」だけでなく「長期的に勝つ」ための道具です。

- **勝率予測** … 各馬の評価を softmax / Bradley-Terry の強さに変換し、正規化して勝率を算出。「自信度（温度）」スライダーで荒れ／堅いを調整。
- **複勝・連系の確率** … **Harville モデル**で、複勝・馬連・馬単・3連複・3連単の的中確率を条件付き確率から厳密計算（勝率の単純合算ではありません）。
- **期待値(EV)エンジン** … 実オッズを入れると EV とケリー基準の推奨賭け額を計算。`+EV` の買い目だけを提示します。
- **買い目最適化** … 確率の高い順に買ったときの「累積的中率」を可視化。的中率と回収率のトレードオフを見ながら点数を決められます。
- **成績記録＆キャリブレーション** … 予想と結果を記録し、回収率・的中率、そして「予測確率 vs 実測」の較正曲線を蓄積。予測のクセを直して精度を高めるための機能です。
- **かんたん／プロの2モード** … ★評価だけの初心者モードと、5項目×重み調整のプロモード。
- 完全オフライン・外部依存ゼロの単一HTML＝**ずっと無料**。

> ⚠️ 競馬は確率的なギャンブルです。的中率100%は数学的に不可能で、本アプリも当たりを保証しません。長期的に的中率・回収率を高める唯一の現実的な方法は「期待値がプラスの馬券だけを買い」「結果を記録して精度を測り続ける」ことです。20歳未満の馬券購入は禁止。無理のない範囲で楽しんでください。

### 📊 競馬予想システム V5.5（`index.html`）
6項目（タイム／近走／距離／馬場／騎手／脚質）を手動でスコアリングし、モンテカルロで着順分布を推定する経験者向けツール。

## 使い方
1. リポジトリを開き、`keiba-ai.html`（または `index.html`）をブラウザで開くだけ。
2. スマホでは「ホーム画面に追加」でアプリのように使えます。
3. GitHub Pages で公開する場合、`index.html` がトップに表示されます。

## 予想エンジンの数学的裏付け
`keiba-ai.html` の確率モデルは、埋め込み前に独立した単体テスト（勝率の正規化、Harville の各式別が確率和=1、EV・ケリー基準）で検証済みです。

- 勝率: `p_i = exp(s_i/T) / Σ exp(s_j/T)`
- 複勝率(top-k): Harville の条件付き連鎖
- 期待値: `EV = p × オッズ − 1`
- 資金管理: ケリー基準 `f = (p·b − (1−p)) / b`（b = オッズ−1）

## プライバシー
すべてのデータは `localStorage` に保存され、外部送信は一切ありません。バックアップは成績タブからJSONでエクスポート/インポートできます。
