# 競馬予想アプリ集

ブラウザだけで動く、無料・オフラインの競馬予想ツールです。インストール不要・サーバー不要・データは端末内のみに保存されます。

## 収録アプリ

### 🏟 競馬予想システム V6.5（`keiba-yosou-v65.html`）— 本流・最新
V6.0（合議AI搭載のフル機能版）を土台に、3Dレースシミュレーション（V6.1〜6.4のジオラマ含む）を統合した最新版です。**既存の全機能を維持**しています。

**全タブ（実機検証済み・JSエラー0）**: チェック（採点）／一覧（指数編集）／シミュ（**クイック・モンテカルロ・展開・展開DNA・🎥3D立体**の5モード）／**指数**（ランキング・レーダー）／記録（較正・収支）／DB／🤖合議AI。

### 🤖 合議AI（V6.0）
本流システム **V5.8** を土台に、**展開DNAシミュレーション（V5.9）** と **合議AI（V6.0）** を積み上げています。

#### 🤖 合議AI（V6.0の目玉・新タブ「AI」）
「長期で勝つ」ための3本柱を、数学的に誠実に1つに統合した頭脳です。
- **🧠 自己学習エンジン** … 記録した「6指数→勝ち馬」を**条件付きロジット（Plackett-Luce）で最尤推定**し、**あなた専用の指標の重みを自動最適化**。少ない記録では既定へ自動収縮（過学習防止）。「データ上は"近走"より"タイム"が効く」といった補正が出ます。
- **🤝 合議（アンサンブル）** … 学習モデル・展開DNA・市場（オッズ）の3確率を**対数線形プールで統合**。各エンジンの寄与を並べて表示し、市場と食い違う**"妙味の穴"**を提示します。
- **📈 市場CLV** … 「買った時オッズ vs 最終オッズ」を記録。**CLVプラス＝市場より先に正解を見つけている**証拠で、回収率より早く実力を示します。
- **🛡 破産リスク・シミュレーター** … 想定エッジ×ケリー係数で1シーズンを1万通り試算し、**破産確率・最大ドローダウン・期待成長**を可視化。規律の理由を体感できます。

#### 🧬 展開DNAモード（V5.9・シミュタブの4つ目）
ペースを「抽選＋補正表」で与える従来手法と異なり、**脚質構成からペースが創発**。スタミナ消耗で先行が失速・差しが台頭する**展開そのものを1レースずつ再現**して集計します。代表レースのアニメ再生＋Harville厳密解とのクロスチェック付き。

- 既存モード・データは無改変。合議AI・DNAの各モジュールは外部依存ゼロで動作します（土台V5.8のグラフはChart.js CDNを使用）。

### 🏇 ウマメーター AI PRO（`keiba-ai.html`）
**展開が創発するレースDNAシミュレーション × 期待値(EV)エンジン**。「当てる」だけでなく「展開を読み、長期的に勝つ」ための道具です。

#### 主な機能
- **🧬 レースDNAシミュレーション（本アプリの発明）** … 出走馬の**脚質構成からペースが自動的に生まれ**、スタミナ消耗で先行馬が失速・差し馬が台頭する**展開そのものを1レースずつ再現**。それを数千回試行して確率を出す「展開が創発するモンテカルロ」。**代表レースをアニメーション再生**し、ペースゲージと展開コメントで"なぜその馬が勝つのか"を可視化します。
- **📊 解析エンジン（勝率・複勝率）** … softmax / Bradley-Terry で勝率、**Harvilleモデル**で複勝・馬連・馬単・3連複・3連単の的中確率を厳密計算。展開込みのシムと突き合わせて「軸の信頼度」を判断できます。
- **💰 期待値(EV)＋ケリー基準** … 実オッズを入れると EV と推奨賭け額を算出。`+EV` の買い目だけを提示。オッズの一括貼り付け入力に対応。
- **🔀 買い目最適化** … 確率順に買ったときの「累積的中率」を可視化。的中率↔回収率のトレードオフを見て点数を決められます。
- **📈 成績ダッシュボード** … 回収率・的中率、**収支推移グラフ**、そして「予測確率 vs 実測」の**キャリブレーション曲線**を蓄積。予測のクセを直して精度を高める改善ループ。
- **📝 近走オート採点** … 近5走の着順を打ち込む/貼るだけ（例：`1 3 2 5 1`）で、クラス補正込みの指数を自動算出し★や各項目へ反映。手入力の負担を大きく削減します。
- **🏅 条件別回収率** … 芝/ダート・距離帯ごとの的中率・回収率を集計し、あなたの"得意条件"を可視化。
- **🛠️ σ自動較正** … 蓄積した記録から「過信/過小」を検出し、自信度T・シミュσをワンタップで自己調整。
- **📌 メモ欄** … 各レースに反省・気づきを記録して振り返りに。
- **かんたん／プロの2モード** … ★評価＋脚質だけの初心者モードと、5項目×重み＋スタミナのプロモード。
- 完全オフライン・外部依存ゼロの単一HTML＝**ずっと無料**。

> ℹ️ V5.8 の OCR画像読取は「実運用で機能しない」ため**あえて採用せず**、同じ目的（手入力の削減）を**確実に動く「近走オート採点」**で実現しています。

#### 「レースDNAシミュレーション」は何が新しいのか
従来手法（下記V5.8を含む多くのソフト）は、ペースを「抽選値＋脚質補正表」で**外から与えます**。本アプリは違い、ペースを**フィールド構成の帰結として内側から創発**させます:

1. 逃げ・先行が多いほど前が競り合い、ペースが自然に上がる（**創発するペース**）
2. 速い流れで先行勢はスタミナを消耗（**エネルギー収支**）
3. 直線で、脚を溜めた差し・追込がスタミナ切れの前を差す（**展開の綾**）

この力学を毎試行シミュレートするため、「ハイペースで差し有利／スローで前残り」といった現実の展開が**確率として自然に出てきます**。単体テスト8項目（確率正規化・ペース創発・展開の綾）で検証済み。

> ⚠️ 競馬は確率的ギャンブルで、**的中率100%は数学的に不可能**（確実な予想があればオッズが1.0倍に収束して利益が消えます）。本アプリも当たりを保証しません。長期的に的中率・回収率を高める唯一の現実的な方法は「展開を読み」「期待値がプラスの馬券だけを買い」「結果を記録して精度を測り続ける」こと。20歳未満の馬券購入は禁止。無理のない範囲で。

## 使い方（PC・スマホ）
1. `keiba-ai.html` をダウンロードしてブラウザで開くだけ（ダブルクリック）。ネット不要。
2. スマホは「ホーム画面に追加」でアプリのように起動。
3. GitHub Pages 公開時は `https://<user>.github.io/keiba_app/keiba-ai.html`。

## 数学的裏付け（検証済み）
`keiba-ai.html` の両エンジンは、埋め込み前に独立した単体テストで検証しています（解析16項目 / シミュレーション8項目 = すべてpass）。

- 勝率: `p_i = exp(s_i/T) / Σ exp(s_j/T)`
- 複勝率(top-k): Harville の条件付き連鎖
- 期待値: `EV = p × オッズ − 1`
- 資金管理: ケリー基準 `f = (p·b − (1−p)) / b`（b = オッズ−1）
- 展開シミュ: ペース創発 `pace = f(Σ 脚質積極性 × 能力)`／エネルギー収支モデル

## プライバシー
すべてのデータは `localStorage` に保存され、外部送信は一切ありません。バックアップは成績タブからJSONでエクスポート/インポートできます。
